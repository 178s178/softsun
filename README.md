# 轻日 1.4 · 安卓日程、学习计时与 DeepSeek Agent

面向个人使用的中文原生安卓 App。暖白与绿色界面，学习页带柔和山林插画和轻微自然动效。日程和学习数据默认保存在本机，基础功能离线可用；主动使用 DeepSeek Agent 时联网。

## 手机安装

[下载 APK 和查看安装指南](INSTALL.md)

1. 把 `dist/qingri-1.4.0.apk` 发送到安卓手机，点击安装。系统若询问，允许当前文件管理器安装应用。
2. 打开“轻日”，点击右下角 **＋** 新建日程。
3. 在“设置”开启 **通知权限** 和 **准时提醒**。可点“10 秒后测试提醒”检查锁屏后是否收到通知。
4. 小米手机请从“后台与省电设置”进入系统应用管理，检查自启动和后台省电限制；具体项目名称取决于系统版本。

支持 Android 8.0 及以上。已在 Android 15（API 35）模拟器完成实际安装和运行验证，尚未在你的真机测试。安装包为本地开发签名的个人使用版。

## 日程管理

- 今日待办、周日期条、月历选日、分类和优先级。
- 新增、编辑、删除、关键词搜索标题/备注/地点。
- 点击卡片右侧圆圈，完成或撤销完成这一次日程。
- 每天、工作日、每周和每月重复。31 日的月度事项在短月落到月末，后续长月仍回到 31 日。
- 重复日程的编辑与删除作用于整个系列；修改开始时间或重复规则会重置该系列的完成记录。
- 跨日事项按时间交集显示；今日页面包含往日未完成事项，重复事项显示近 30 天。
- 提醒可选择准时或提前。时间过近、原提前时间已过时，会回退到开始时间提醒。
- 通知可以直接“完成这一次”。编辑或恢复后，旧通知和旧操作失效。

系统提醒由一个闹钟驱动持久化队列，同一时刻的多条日程均参与处理。应用更新、设备重启、时间或时区变化后会重建调度。精确闹钟未授权时使用系统的不精确调度，可能延迟。通知渠道关闭时会显示关闭，且不会把未送达的提醒当作已送达。强行停止 App 后，需要重新打开才能恢复调度；厂商后台限制仍需在真机确认。

## 学习模式

底部点击 **学习** 进入。

- **开始学习**：自由正计时，不强制限定时长。
- **暂停 / 继续学习**：暂停期间不计入有效时长。
- **结束本次**：手动结束并记录有效学习时长和次数。
- 点击返回或离开 App 后仍按真实经过的时间计算；重新打开可以继续控制。
- 可选择保持屏幕常亮；默认关闭。
- 计时使用单调时钟，手动校时不会使时长跳变。进程重建后恢复；设备重启后自动暂停，保留最后保存的计时进度。
- 学习结束使用唯一会话标识，重复操作或中途重启不会把同一次记录重复累计。

山林插画使用原生 Canvas 绘制；系统关闭动画或开启省电模式时，插画保持静态。学习模式不会锁住手机，也不会要求必须达到某个时长才能结束。

## 时间记录与扇形统计

底部点击 **记录**，可切换 **日统计 / 月统计**，使用左右箭头或点击日期选择其他日期、月份。

- 每次学习是一个独立扇区；百分比以所选期间内已记录的有效时长为基数。
- 3D 图采用俯视顶面、厚度侧壁和柔和投影。点击或选择明细后，扇区外移抬起；顶面和侧面均可点选，点选时图表保持原位。
- 点击扇区或明细，会高亮同一次记录，查看名称、开始/结束时间、有效时长和占比。
- 学习开始前可以填写名称；结束后自动入账。进行中的学习暂不纳入图表。
- 支持 **补记时间**，选择起止时间和名称；记录详情中可以改名、删除。
- 月视图还可查看每日汇总，进一步进入某天的明细。
- 跨午夜或跨月的学习按实际有效片段拆分，暂停不计时。旧版缺少片段的历史记录按时间跨度分配，跨日时提示估算。
- 没有记录时显示空状态；不足一分钟的记录仍显示秒数。

1.4 使用相同签名，可以覆盖安装并保留日程、学习记录和有效总时长。

## 日程 Agent

首页右上角打开 **日程 Agent**。密钥默认留空，可稍后在 **模型设置** 或 **设置 → DeepSeek 接口** 填写；默认使用官方接口与 `deepseek-flash`。未配置时不会请求网络，也不会生成假建议。

- 描述目标，选择日期、可用时间及专注/休息间隔，生成当天建议。
- 需要优化时，勾选允许调整的未来非重复日程；未选事项全部保留为固定占用。
- 预览时间、理由和暂未排入的任务，选择条目后点击 **采纳** 才会写入日程。原日程保持标题、时长、备注和地点，不自动删除。
- 采纳时重新检查当前占用、原日程变化和当前时间；同一建议重复点击不会重复保存。部分采纳会计入未采纳原日程的占用。
- 可停止生成；失败不会写入日程。保存期间若退出，重新打开后先核对日程，避免把已提交的操作误认为已取消。

密钥通过 AndroidKeyStore AES-GCM 加密，不进入备份或源码。在线调用发送本次目标、选中日程的标题、占用时间和近7天聚合学习量，不发送备注、地点或固定日程标题。服务商可能按使用量收费。真实 API 调用尚未测试，因为按用户要求密钥留空。

在日程 Agent 或设置页打开 **Agent 记忆**。开启后可填写长期偏好，成功采纳时会更新最近一次使用的时间窗口、专注和休息参数。点 **使用上次参数** 可把这些参数填入本次草稿。生成时，DeepSeek 会收到已开启的记忆作为参考，实际排程采用本次输入。记忆默认关闭，可随时编辑、停用或清除，保存在本机并独立于日程备份。

本次代码精简统一草稿状态收集与取消清理，复用工具参数结构和整数解析。排程使用有界的确定性规则，不保证全局最优；不会为了尝试优化而自动改写原安排。

## 本地备份

在“设置”导出 JSON，包含日程、完成记录、提醒记录与已完成学习记录。进行中的计时不包含在导出文件中，建议结束本次学习后再备份。

恢复前会请求确认，并先完整校验再开启事务。损坏文件、重复 ID、错误类型、无效日期等不会覆盖原数据。v3 备份保存记录名称、有效片段和历史估算标记；兼容 v1/v2。v2 恢复旧日程与学习记录，v1 仅替换日程并保留现有学习记录。

单个备份支持 64 MiB、20,000 条日程，以及各 200,000 条状态/学习记录。导出与导入使用相同限制；超出时会报错，不会提示导出成功。卸载应用会删除本机数据，请先完成备份。

## 从源码构建（Windows）

需要 Python 3 和 PowerShell 7。脚本会优先使用本机已有的 JDK；下载的 Android 官方工具放在 `.tools`，不会全局安装 IDE 或修改系统环境变量。

```powershell
cd D:\zuoye\qingri
python scripts/setup_tools.py
pwsh -File scripts/test.ps1
pwsh -File build.ps1
```

输出 `dist/qingri-1.4.0.apk`。构建使用 Android API 35、Build Tools 35.0.1 和 Java 8 兼容字节码，不依赖第三方 Android 运行库。JDK 17 或 21 可以构建。

保留项目中的 `.tools/signing/qingri-local.keystore` 才能用相同签名覆盖安装后续版本。源码压缩包不包含该私钥；在另一目录首次构建会生成新签名。

## 测试

纯 Java 测试：

```powershell
pwsh -File scripts/test.ps1
```

Android 15 模拟器与设备测试：

```powershell
python scripts/setup_emulator.py
pwsh -File scripts/start_emulator.ps1
# 等待模拟器启动完成后
pwsh -File build.ps1 -WithTests
pwsh -File scripts/android_test.ps1 -Mode storage
pwsh -File scripts/android_test.ps1 -Mode regression
pwsh -File scripts/android_test.ps1 -Mode ui
pwsh -File scripts/android_test.ps1 -Mode denied
# 时间记录测试使用独立 instrumentation，见 docs/verification-1.2.md
```

这些测试只用于本地测试模拟器 `emulator-5556`，部分测试会清空其 App 数据、放入示例日程或改变测试权限。请勿对保存了个人数据的设备执行。`channel` 模式需要先在模拟器系统设置中单独关闭“日程提醒”渠道，同时保留应用整体通知权限。

测试日志位于 `build/qa`。实际界面截图中的示例数据只存在于测试模拟器；安装到手机后默认没有示例日程。

## 源码结构

| 文件 | 用途 |
|---|---|
| `ScheduleEngine.java` / `AlarmPlan.java` | 重复、日期交集、下一次提醒与持久化队列计划 |
| `EventStore.java` | SQLite、备份校验、事务恢复、学习历史 |
| `ReminderScheduler.java` / receivers | 权限状态、系统闹钟、通知及恢复调度 |
| `MainActivity.java` / `MonthGrid.java` | 日程、月历、设置 |
| `EditorActivity.java` | 日程编辑 |
| `StudyTimer.java` / `StudySession.java` | 单调时钟计时、有效片段和可恢复的学习会话 |
| `FocusActivity.java` / `NatureView.java` | 学习模式和自然插画 |
| `TimeStats.java` / `TimeRecordStore.java` | 按日/月分配、单次占比与记录存储 |
| `RecordsActivity.java` / `PieView.java` | 时间记录、扇形图与明细 |
| `AgentActivity.java` / `AgentService.java` | 规划输入、工具上下文、建议与事务采纳 |
| `AgentMemory.java` / `AgentMemoryDialog.java` | 本机规划记忆与管理入口 |
| `AgentPlanner.java` / `DeepSeekAgent.java` / `AgentSettings.java` | 可行性排程、模型工具协议与加密配置 |
| `Ui.java` | 原生界面样式与图标 |

1.4 的记忆设计与验证见 `docs/superpowers/plans/2026-11-07-agent-memory.md`。旧版本验证记录见 `docs/verification-1.3.md`、`docs/verification-1.2.md` 与 `docs/verification.md`。
